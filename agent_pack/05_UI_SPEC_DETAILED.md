# 05_UI_SPEC_DETAILED — экраны и состояния

Версия 1.0 · 20.11.2026. Стиль — 06_DESIGN_TOKENS, виджеты — 07_WIDGETS_SPEC.

## 0. Каркас
- Десктоп (≥1024): левое меню (Обзор, Объекты, Тревоги, Графики, Правила, Расписания, Журнал, Настройки), верхняя строка: выбор объекта, статус БС (●/✕), счётчик тревог, пользователь.
- Телефон: нижняя панель — Обзор · Тревоги · Управление · Ещё.
- AlarmBanner: на всех экранах, пока есть P1 active_unacked: «⚠ Давление 1,2 бар — Насосная-1 · 09:14 [Подтвердить] [Открыть]».
- Бейдж «ТЕСТ» в шапке при client_flags.sim_mode.

## 1. Вход (/login)
Логотип, логин, пароль, «Войти». Ошибка — «Неверный логин или пароль». 5 неудачных попыток → «Слишком много попыток, повторите через минуту» (RATE_LIMIT).

## 2. Обзор (/)
Карточки объектов: название, тип (иконка), постов онлайн N/M, активные тревоги по приоритетам, работающие устройства. Пусто → «Объектов нет — [Добавить объект]».

## 3. Объект (/o/:id)
- Переключатель вида: [3D-сцена] [Дашборд] [Карта]. По умолчанию — 3D (если WebGL), иначе дашборд.
- 3D: scene3d на всю область; клик по посту → правая панель поста (на телефоне — нижний лист).
- Дашборд: сетка виджетов; кнопка «Редактировать» → конструктор (07 §4); «Сохранить» / «Отмена».
- Полоса статуса: «Связь с объектом: обе БС онлайн» / «Нет связи с БС-1 с 08:40».

## 4. Пост (/o/:id/p/:postId)
Шапка: название, участок, модем (батарея В, запас SNR дБ, RSSI по БС, последняя связь). Блоки: текущие значения (карточки), soil3d (если ≥ 2 глубины), график 24 ч, исполнители поста (мини-панели управления), тревоги поста.

## 5. Устройство (/a/:id) — главный сценарий
```
Клапан 3 · Пост 7 · Участок Б          Режим: [Авто | Ручной]
Факт: ● Выключено · подтверждено 09:10
Длительность: [30 мин ▾] (макс 4 ч)
[ ВКЛЮЧИТЬ ]                    [ ВЫКЛЮЧИТЬ ]
Создана → В очереди → Передано шлюзом → ✓ Подтверждено
История команд (10 последних)
```
Правила:
- Длительность: пресеты 10/15/30/60 мин, 2/4 ч + ввод; больше max → кнопка неактивна, подсказка «максимум 4 ч».
- Работает (fact_state on) → «ВКЛЮЧИТЬ» превращается в «ПРОДЛИТЬ»; показывается «до 10:45 (осталось 23 мин)».
- Политика требует подтверждения → диалог «Включить Клапан 3 на 30 мин?» с кнопкой «Удерживайте 1,5 с для подтверждения»; отмена закрывает и вызывает /cancel.
- ВЫКЛЮЧИТЬ — без диалога всегда.
- Статусная цепочка (StatusTrail): текущий шаг выделен; ✓ «Выполнено» только на acked/completed; timeout → «Не подтверждено модемом» + [Повторить]; rejected → «Модем отклонил команду (код N)»; cancelled → причина; warning MODEM_OFFLINE → «Модем не на связи: команда ждёт до HH:MM».
- Режим Ручной → подсказка «Расписания и автоматика не выполняются для этого устройства».
- Форточка: кнопки ОТКРЫТЬ / ЗАКРЫТЬ, без длительности.
- Двойной клик/повторное нажатие: кнопка блокируется до ответа API; повтор использует тот же idempotency_key.

## 6. Тревоги (/alarms)
Таблица: приоритет (цвет+текст), объект/пост, сообщение, время, состояние, шаг эскалации, [Подтвердить], [К устройству]. Фильтры: активные / неподтверждённые / все; объект; приоритет. На телефоне — карточки. Подтверждение — без диалога, с отметкой «Подтвердил demo 09:20».

## 7. Графики (/charts)
Выбор тегов (дерево Объект → Пост → Параметр, поиск), до 8; период 24 ч / 7 д / 30 д / свой; агрегация; «Сохранить вид» (сохраняется в dashboards). При 9-м теге — «Не более 8 рядов».

## 8. Правила (/rules) и расписания (/schedules)
- Список: имя, устройство, статус (Утверждено / Ждёт утверждения / Выключено), последний запуск.
- Мастер правила (4 шага): 1) условие: тег, оператор, значение; 2) действие: команда, длительность; 3) гистерезис, пауза, «при отсутствии данных»; 4) сводка человеческим языком + [Утвердить и включить] / [Сохранить черновик].
- Изменение утверждённого правила → предупреждение «После изменения правило потребует повторного утверждения».
- Расписание: время, дни недели, команда, длительность; при OVERLAP — жёлтое предупреждение.

## 9. Журнал (/audit)
Лента: время, кто, событие (человекочитаемо), объект; раскрытие — было/стало. Фильтры по периоду, сущности, автору. Пагинация 100.

## 10. Настройки
- Объекты и посты: название, object_type (список: виноградник, сад, теплица, насосная, поле, другое), координаты; для поста — позиция в 3D (scene_x/y, перетаскиванием в сцене).
- Ввод модема (onboarding): список модемов с неназначенными каналами → экран привязки: слева каналы (живое значение, «Влажность грунта −10 см №1»), справа посты; перетаскивание или выбор; диапазон и поправка — по желанию; «unknown_code» — серым «Нет в справочнике».
- Команды: для каждой — политика подтверждения (4 варианта с пояснением), длительность по умолчанию / максимум; смена на «Без подтверждения» для пускателя → предупреждение.
- Тревоги: определения (тип, тег, порог, приоритет, гистерезис), цепочки эскалации (шаги, задержки, каналы); недоступные клиенту каналы — неактивны с подсказкой.
- Внешние источники: провайдер, объект, вкл/выкл, последний успех.
- Симулятор: вкл/выкл (только чтение флага, если API не даёт менять).

## 11. Общие состояния
| Состояние | Вид |
|---|---|
| Загрузка | скелетоны, не спиннер на весь экран |
| Пусто | иллюстрация + действие |
| Ошибка API | карточка «Не удалось загрузить» + [Повторить] |
| Нет связи с сервером | жёлтая полоса сверху |
| Данные устарели | серый виджет «обновлено N мин назад» |
| Нет WebGL | 2D-замена с подписью |
