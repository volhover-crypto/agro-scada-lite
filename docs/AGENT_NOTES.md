## 3. Технические уроки (не все попали в DECISIONS)

- После прохода Prettier перечитывать файл перед следующим Edit (сдвиг строк ломает замены); python-скриптовые замены по prettier-файлам ненадёжны (урок T14, журнал PROGRESS).
- `git grep`/`grep` по prettier-таблицам: после ре-выравнивания таблиц сравнивать по содержимому, не по ширине колонок.
- e2e (Playwright): таймауты 15 с флакают при параллельном прогоне — держать 30 с+; `page.goto()` между страницами сбрасывает мок-стор (D-25) — после командных действий навигация только клиент-сайд; на 360 px метки постов в 3D перекрываются (force-клик попадает в верхнюю) и низ панели поста перекрыт нижним баром — использовать `dispatchEvent('click')`; «Открыть пост» — link, не button.
- Vitest: страницы рендерить внутри `<Routes><Route>` (иначе `useParams` пуст); EChartCanvas в jsdom — vi.mock-стаб; мок-сценарий задавать через `?scenario=` в sessionStorage до `worker.start()` (D-21).
- Данные `/updates` мержатся в плоские ключи кэша (`['commands']`, `['actuators']`, `['alarms']`) — экраны с живыми данными поллят сами (refetchInterval), см. `src/state/updates.ts`.
- `npm run build` выводит «build exit=$?» явно — иначе код выхода теряется в пайпе.
