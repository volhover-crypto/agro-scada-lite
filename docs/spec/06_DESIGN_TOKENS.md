# 06_DESIGN_TOKENS — стиль AgroЭЛЕМЕНТ

Версия 1.0 · 20.11.2026. Основная тема — светлая бежевая (как сайт AgroЭЛЕМЕНТ). Тёмная — опционально (should).

## 1. Брендовые материалы
Владелец передаёт логотип (SVG) и точные цвета бренда. Положить в `src/assets/brand/`:
`logo.svg`, `logo-mark.svg` (знак без текста), `brand.json` (цвета HEX).
Пока файлов нет — использовать значения ниже, помеченные `[approx]` (сняты со скриншота сайта). При получении `brand.json` заменить только переменные `--brand-*`.

## 3. Типографика
- Шрифт: из `brand.json`; по умолчанию Inter (подключить локально через npm `@fontsource/inter`), цифры — `font-variant-numeric: tabular-nums`.
- Размеры: 12 / 14 (база) / 16 / 20 / 24 / 32; заголовки 600, текст 400.
- Крупные значения в виджетах: 28–40, 600.

## 4. Сетка и формы
- Отступы: шкала 4 px (4, 8, 12, 16, 24, 32).
- Радиусы: карточка 14 px, кнопка 10 px, круглая CTA — 50%.
- Дашборд: 12 колонок ≥1280 px; 6 — 768–1279; 1 колонка <768.
- Касание: минимум 44×44 px; главные кнопки управления на телефоне ≥ 56 px высотой.

## 5. Иконки и иллюстрации
- Иконки: линейные, 1.75 px (Lucide или аналог).
- Иллюстративный стиль 3D-сцен — изометрия, тёплые земляные тона почвы (#8B6A47, #6E5236), зелень #6F9A3E, металл/контроллер #4A4F55, линии данных — --brand-blue.

## 6. Движение
150–250 мс ease-out для интерфейса; пульсация «ожидание» 1.2 с; уважать `prefers-reduced-motion` (3D без автоповорота).

## 7. Доступность
Контраст текста ≥ 4.5:1 на --bg-surface. Статус никогда не передаётся только цветом — всегда текст или значок.
