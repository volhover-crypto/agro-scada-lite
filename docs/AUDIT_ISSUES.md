- Статус: **закрыто 2026-11-22, FIX-4** (решение владельца): добавлен e2e `e2e/device.spec.ts` «FIX-4: смена режима — ошибка сервера видна пользователю» — отказ имитируется тумблером «Ломать смену режима (423)» панели отладки мока (04_MOCK_SPEC §5).
