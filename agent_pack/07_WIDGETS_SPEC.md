# 07_WIDGETS_SPEC — виджеты

Версия 1.0 · 20.11.2026. Все виджеты — компоненты `src/widgets/*`, конфиг хранится в `dashboards.layout` (JSON) через API.

## 1. Общий контракт виджета
```ts
type WidgetConfig = {
  id: string;
  kind: 'gauge'|'lamp'|'card'|'chart'|'bar'|'table'|'map'|'scene3d'|'soil3d';
  title?: string;
  tags: string[];            // tag_id, формат {dev_eui}/{code}/{level}/{no}
  thresholds?: { value: number; color: 'ok'|'warn'|'alarm' }[];
  options?: Record<string, unknown>; // по виду
  grid: { x: number; y: number; w: number; h: number };
};
```
Каждый виджет обязан:
1. показывать качество данных по 06_DESIGN_TOKENS (stale, offline, ошибка, прогноз, ТЕСТ);
2. показывать время (`ts_measured`, иначе `ts_received` + «время приёма»);
3. иметь состояния: загрузка (скелетон), нет данных, ошибка API (кнопка «Повторить»);
4. по клику открывать подробности тега (график 24 ч, привязка, пост).
Данные: `/tags/current` (опрос 30–60 с) и `/tags/history`.

## 2. Виджеты 2D
| kind | Что | Опции | Поведение |
|---|---|---|---|
| gauge | стрелочный индикатор | min, max, зоны цвета, единицы | плавный ход стрелки 300 мс; вне диапазона — стрелка у упора + статус ошибки |
| lamp | сигнальная лампа | правило: дискрет 0/1 или порог; подписи вкл/выкл | цвет + текст; «неизвестно» — жёлтый контур |
| card | последнее значение | точность, единицы, мини-тренд 24 ч | крупное число, стрелка тренда ↑↓ |
| chart | временной ряд / наложение | до 8 тегов, 2 оси Y (по единицам), период, агрегация avg/min/max, прогноз пунктиром, пороги линиями | зум колесом/щипком, курсор с значениями всех рядов, сохранение вида |
| bar | столбцы/диаграмма | агрегат по периоду (сутки, неделя), группировка по постам | напр. осадки по дням, полив по постам |
| table | таблица телеметрии | колонки: пост, параметр, значение, качество, время | сортировка, фильтр, экспорт CSV (should) |

## 3. 3D-виджеты (MVP)
Реализация: three.js через @react-three/fiber + drei. Ленивая загрузка (code-split). Если WebGL недоступен — показать 2D-замену (map / chart) с подписью «3D недоступно на этом устройстве».

### 3.1 scene3d — изометрическая сцена объекта
- Камера: изометрическая (ортографическая, ~35°/45°), вращение ограничено ±45°, зум, сброс вида; на телефоне — жесты.
- Поверхность: плоский участок (или по контуру из `objects`/`posts` координат — проекция lat/lon в метры), ряды культур — упрощённые низкополигональные модели (столбы + шпалера / деревья / теплица — по типу объекта, `options.objectStyle`).
- Посты: модель контроллера «ТОЧКА» (low-poly коробка с антенной) на позиции поста; цвет кольца под постом = худший статус его тегов/тревог.
- Подписи: HTML-метки над постом: название, 1–3 ключевых значения (`options.labelTags`), время; при активной тревоге — красный значок.
- Исполнители: насосы/клапаны — значки у поста; вкл — анимация потока (синие частицы по трубке), ожидание — пульсация.
- Линии связи: пунктир от поста к БС, цвет по качеству связи (margin, RSSI).
- Клик по посту → боковая панель поста (значения, устройства, кнопки управления).
- Производительность: ≤ 15 постов × 5 датчиков — 60 FPS на среднем ноутбуке, ≥ 30 FPS на телефоне; инстансинг для рядов.

### 3.2 soil3d — разрез почвы с профилем влажности
- Вид: изометрический блок грунта (разрез), слои по глубинам датчиков поста (level_cm < 0).
- Датчики: капсулы на своих глубинах, подпись «−10 см · 27,4 %».
- Профиль: заливка градиентом между глубинами по значению влажности (шкала сухо #C9A26B → норма #7FA650 → переувлажнение #2F7FD8; границы — `options.moistureZones`).
- Время: ползунок по истории 24 ч / 7 д (данные `/tags/history`), кнопка «воспроизвести» — анимация смены профиля.
- Дополнительно: температура грунта — второй режим заливки (переключатель).
- Если глубин < 2 — показывать подсказку «для профиля нужно ≥ 2 датчиков на разных глубинах».

## 4. Конструктор дашборда (MVP)
Сетка с фиксированными шагами (react-grid-layout или аналог): добавить виджет → выбрать вид → выбрать теги (поиск по посту/параметру) → пороги → сохранить. Свободное перетаскивание и изменение размера — на десктопе; на телефоне — только порядок.

## 5. Приёмка виджетов
1. Каждый вид отображает все статусы качества на моке (MOCK_SPEC сценарий «качество»).
2. chart: 8 рядов с двумя единицами → 2 оси Y; прогноз пунктиром.
3. scene3d: 15 постов, статус и метки обновляются без перезагрузки сцены.
4. soil3d: профиль по 3 глубинам, ползунок времени меняет заливку.
5. Без WebGL — 2D-замена.
