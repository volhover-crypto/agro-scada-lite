## Итоговый пакет изменений для бэкендера (в `03_API_CONTRACT.yaml` v1.1)

Все открытые вопросы закрыты. В новую версию контракта v1.1 включаются:

1. **BR-FE-1** — `base_stations` в ответе `/updates` (`{code, last_seen, online}` по объекту).
2. **BR-FE-2** — раздел `/settings/external_sources` (`provider`, `object_id`, `enabled`, `last_ok`).
3. **BR-FE-3** — `RATE_LIMIT`: HTTP 429 + `error.code=RATE_LIMIT`, окно 5 попыток / 60 с на `/auth/login`.
4. **BR-FE-4 + BR-FE-5** — по-разделочная типизация `GET /settings/{section}` для всех 8 разделов (`command_defs`, `alarm_defs`, `chains`, `channels`, `client`, `param_dict`, `actuators`, `external_sources`). Списочные разделы в MVP — read-only (**BR-FE-7** перенесён в v2).
5. **BR-FE-6** — `sim_mode` только чтение в `client_flags` ответа `/updates`; политика срабатывания правил/тревог на `sim`-данных — на усмотрение бэкендера.
6. **Пост-MVP (не требуются для стыковки v1.1):** `PUT /settings/{section}` для списков (BR-FE-7), `actuator_id` в `Alarm` (BR-FE-8), `PUT /posts/{id}` (BR-FE-9), `GET /export` (Audit §8.5).
