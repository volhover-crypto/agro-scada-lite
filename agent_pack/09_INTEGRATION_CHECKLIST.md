# 09_INTEGRATION_CHECKLIST — стыковка с бэкендом

Версия 1.0 · 20.11.2026.

## A. Готовность фронтенда (делает агент, T19)
- [ ] `VITE_USE_MOCK=false npm run build` — в бандле нет MSW и панели отладки (проверка поиском по dist).
- [ ] base path `/dash/`, ассеты грузятся из `/dash/assets/*`; обновление страницы на любом маршруте работает (SPA fallback).
- [ ] Все вызовы идут на `VITE_API_BASE` (по умолчанию `/webhook`); нет абсолютных URL и ключей в коде.
- [ ] `contract/03_API_CONTRACT.yaml` совпадает с версией пакета; `docs/CONTRACT_REQUESTS.md` передан владельцу.
- [ ] README_DEPLOY.md: как собрать, куда положить dist, какие переменные.

## B. Готовность бэкенда (подтверждает бэкендер)
- [ ] Реализованы пути контракта (или список отсутствующих с датами).
- [ ] /auth/login выдаёт Bearer-токен; прочие пути без токена → 401.
- [ ] Ответы проходят валидацию по схеме (тот же тест, что для мока, запущенный против стенда).
- [ ] /updates отдаёт изменения по since; server_ts монотонен.
- [ ] Немедленные события (ack 0x30, 0x40) появляются в /updates ≤ 30 с.

## C. Инфраструктура (бэкендер/владелец)
- [ ] Caddy: раскомментирован блок `/dash/*` → каталог dist с fallback на index.html; `/webhook/*` → n8n; остальное 403.
- [ ] Один домен для `/dash` и `/webhook` (без CORS). Если домены разные — CORS только для домена дашборда.
- [ ] TLS включён (Let's Encrypt или internal) — PWA требует HTTPS.
- [ ] UI n8n (:5678) и bridge (:8081) снаружи недоступны (проверка curl → 403/timeout).

## D. Совместная приёмка (на тест-стенде Vega)
1. [ ] Вход, обзор объектов, object_type отображается.
2. [ ] Живые значения с тест-стенда в карточках; время «измерено/получено».
3. [ ] Новый канал → «неназначенные» → привязка → значение на посту.
4. [ ] Команда на модем класса C: queued → sent_gw → acked → completed; «Выполнено» только после ack.
5. [ ] Отключение модема → offline/stale; команда с warning MODEM_OFFLINE → cancelled по TTL.
6. [ ] Порог давления → тревога, оповещение по разрешённому каналу, эскалация.
7. [ ] Журнал содержит все действия пп. 3–6 с автором.
8. [ ] Телефон 360 px: установка PWA, включение полива.

## E. Порядок переключения
1. Бэкенд закрывает B, инфраструктура — C.
2. Сборка `VITE_USE_MOCK=false`, выкладка dist в каталог Caddy.
3. Прогон D; дефекты → issues с меткой `integration`, сторона (FE/BE).
4. Откат: вернуть предыдущий dist (хранить 2 последних сборки).
